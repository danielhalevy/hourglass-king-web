# The Hourglass King - play in the browser

Browser build of The Hourglass King (a side-view action-adventure made for phones).

Play: https://danielhalevy.github.io/hourglass-king-web/

- Open the link in Safari or Chrome on a phone, in landscape.
- iPhone: Share > Add to Home Screen for a full-screen launch.
- The first load downloads about 100 MB; later loads are cached.
